# arena web client (M4)

The old practice tool's look and flows, driven by the WASM engine. The client contains no game logic: every legal control is exactly a `NeutralAction` from `Game.legal()`.

## Run

From the repo root (`--out-dir` is relative to the `wasm/` crate):

```
wasm-pack build wasm --target web --release --out-dir ../ui/pkg
cd ui && npm install && npm run dev
```

Production build: `npm run build` then `npm run preview`. `npm run typecheck` is `tsc --noEmit`.

## Deploy

Deployed by Vercel from `main` via `vercel.json` + `scripts/vercel-build.sh`; the project is linked by the owner's Vercel team, nothing to configure in the repo.

`VITE_BASE` (default `/`) still prefixes public fetches when set. Vercel leaves it unset. Optional local prefix check: `VITE_BASE=/arena/ npm run build && VITE_BASE=/arena/ npm run preview`, then open http://127.0.0.1:4173/arena/.

Card image hashes live in `ui/public/catalog-images.json` (generated by `tools/gen-ui-catalog.mjs` from `cards/official/catalog.json`) — not in the WASM binary — so a catalog refresh does not require `wasm-pack`. The same script copies `oracle/decks/*.json` into `ui/public/decks/` and writes `decks/manifest.json`.

The plain harness at `ui/dev/` is unchanged (debug page).

## Modes

Set in the settings drawer (hamburger / Ctrl+Shift+M):

- **Hotseat** — both sides human; both hands visible (owner ruling 2026-08-13).
- **Play vs bot** — human A, B, or coin; bot policy from `botPolicies()`; "hide the bot's hand" defaults on.
- **Watch bots** — policy per side; Step / Play / Pause and a speed slider (1 action/s … as fast as the tab will paint). Both hands visible. Max speed yields with `requestAnimationFrame`.

Share URL: `?seed=&deckA=&deckB=&mode=`.

## Positions

The engine cannot deserialize `Game.full()` today, so Save/Load/Export/Import store a **replayable action log**: `{ seed, decks, first, NeutralAction[] }`. Replay is `new Game` + `apply` in order. Checkpoints (F6 / F7) are live `Game.clone()` snapshots.

Undo / redo is a ring of `Game.clone()` snapshots taken before each `NeutralAction` (limit 200). Keys match the old tool: Ctrl/Cmd+Z undo; Ctrl+Y, Ctrl/Cmd+Shift+Z redo. Mid-choice undo jumps to the state before the choice began. In Play vs bot, one undo returns to the human's previous decision (bot steps ride on the redo stack and replay identically). Watch steps one bot action at a time when paused.

## Bindings added in this milestone

`Game.acting`, `Game.active`, `Game.turn`, `Game.winner`, `Game.botAction(policy, seed)`, `botPolicies()`. `"random"` and `"first-legal"` pick from `legal()` with `policy_rng(seed)` until RY's `engine::policy` is on `main`; then every name (including `"h0"`) routes through that module and the client's selector grows the new name with no other change.

## Ported / not ported

Ported: deck select + JSON import, seed / first / share URL, mulligan, board (red top / blue bottom, active-on-bottom), hands, art + keyword icons + evolved art, Ward/Storm badges, floating combat text, leader HP, EP/SEP, PP + Bonus PP toggle, crests, counts, play / enhance-as-offered / fuse / engage, attacks, evolve / super-evolve, choice modal, end turn, undo/redo, history drawer, checkpoints, tooltips + large art, terminal + rematch (swap sides), play-vs-bot, watch-bots.

Not ported: blackbox, sparring-line scripts, puzzles, coverage banner, god-mode (everything is already visible; vs-bot hide-hand replaces it).
